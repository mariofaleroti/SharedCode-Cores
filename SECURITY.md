# Security policy

## Supported version

Security fixes are currently applied to the latest `1.x` release.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Contact the repository owner privately through the contact method listed on the GitHub profile and include:

- affected package and version;
- reproduction steps;
- expected impact;
- any proposed mitigation.

Do not include real customer files, credentials, tokens, or personal information in the report.
